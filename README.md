# Site pessoal — Etapa 1

**Aluno:** Matheus Fernandes (nome adotado do perfil GitHub conectado; confirmar antes da entrega).

**Objetivo:** criar a primeira versão de um site pessoal somente com HTML, praticando estrutura semântica, títulos, parágrafos, navegação, imagens, listas, links e formulário. Não há CSS, JavaScript ou frameworks.

**Site:** [Acessar o site pessoal](https://matfernandex.github.io/site-pessoal/).

**Repositório:** [MatFernandex/site-pessoal](https://github.com/MatFernandex/site-pessoal).

## Abrir e personalizar

Abra `index.html` diretamente no navegador. Confirme o nome e substitua os campos “A informar” por curso, instituição, período e e-mail; ajuste a apresentação e inclua outros perfis, se desejar. O formulário é demonstrativo e não envia nem armazena dados. A imagem é local.

## Histórico e publicação

As próximas etapas devem continuar neste repositório: HTML → CSS → layout responsivo. A tag `v1.0-html` identifica esta etapa. Faça um commit a cada evolução.

Para publicar, envie o repositório para o GitHub e, em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve. Consulte as [instruções oficiais do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/creating-a-github-pages-site).

**Verificação da etapa 1:** HTML validado pelo Nu Html Checker do W3C sem erros ou avisos; imagem local, navegação interna e campos do formulário conferidos no navegador.
